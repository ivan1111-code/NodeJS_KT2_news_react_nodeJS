в проекте есть 2 папки: server, client

server: файлы js, файл package.json
client: файл html

как запустить для проверки:

// у вас должен быть node, npm

1. скачайте файлы из server
2. скачайте файл html из client 
3. установите express и cors для сервера командой npm install, находясь в папке server
4. запустите сервер командой node app.js
5. откройте файл html через five server или другой любой инструмент
